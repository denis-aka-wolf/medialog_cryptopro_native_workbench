# Следующий обязательный этап: реализация C++ Bridge на CAdES SDK

В исходном архиве найдены:
- `SDK CSP/cadessdk.msi` (пакет CAdES SDK);
- `SDK CSP/sdk.zip`;
- `SDK CSP/sdk/samples/CSP/CryptMsgSign/CryptMsgSign.cpp`;
- `SDK CSP/sdk/samples/CSP/SigningHash/SigningHash.c`;
- документация CHM `cades.chm` и `CpPkiSdk.chm`.

В `sdk.zip` подтверждён пример низкоуровневой подписи через CryptoAPI `CryptMsg*`. Он полезен для изучения CSP/CMS, но не является доказательством формирования CAdES-подписи нужного профиля. Для реализации CAdES требуется извлечь именно `cadessdk.msi` и изучить предоставляемые им headers, import libraries, samples и документацию.

## Что требуется извлечь из MSI на Windows

На машине Windows с установленным 7-Zip/Orca или другим MSI inspection tool:

1. Распаковать `cadessdk.msi` в отдельный каталог, не устанавливая поверх рабочей системы.
2. Сохранить структуру каталогов.
3. Найти `.h`, `.lib`, `.dll`, `.tlb`, примеры `.cpp/.c` и README.
4. Зафиксировать версию SDK и архитектуру библиотек (x86/x64).
5. Проверить лицензионные условия распространения SDK и runtime.

Передать разработчику перечень файлов и содержимое публичных заголовков/примеров, необходимых для вызова CAdES API. Не публиковать закрытые ключи, сертификаты с приватными данными или PIN.

## Требуемые функции C++ Bridge

- `status`: версии Windows, CSP и доступность именно CAdES SDK API.
- `list-certificates`: перечисление сертификатов CurrentUser\My и доступность private key.
- `sign-detached`: CAdES-подпись требуемого профиля.
- `sign-attached`: CAdES-подпись требуемого профиля.
- `verify-detached`: проверка подписи и содержимого.
- (позже) `verify-attached`, проверка цепочки, CRL/OCSP, timestamp и расширенные сведения.

Реализация должна использовать SDK API, подтверждённый заголовками и примерами установленной версии. Не придумывать имена функций/структур и не подменять CAdES на обычный CMS.

## Acceptance criteria

- C++ проект собирается x64 в Release.
- `stdout` содержит только один JSON-ответ.
- Ошибки идут в `stderr` и JSON `error`.
- Detached подпись проверяется на исходном файле.
- После изменения исходного файла проверка не проходит.
- Attached подпись проверяется независимым валидатором.
- Подтверждён требуемый профиль CAdES и формат контейнера.
- Проверена работа на заявленных версиях Windows Server под эксплуатационной учётной записью.
